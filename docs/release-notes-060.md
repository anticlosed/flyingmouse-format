# v0.6.0 Release Notes

## ⚠️ 重要变更：部分格式已下架

**为符合合规要求，v0.6.0 起不再支持音乐平台加密特殊格式的解密/转换**：

- 已下架：NCM、mflac/mgg、KGMA、KGG、KWM、VPR、mmp4（musicex）等加密音频格式的解密与转换
- 已下架：QQ 音乐登录凭据（cookie）教程、在线换密钥链路、酷狗密钥库相关功能
- 已移除：自动更新功能

**现在音频仅支持普通格式转换**：MP3 / WAV / FLAC / M4A / AAC / OGG / OPUS / WMA 互转。
**不支持**其他音乐平台的特殊格式（NCM / KGG / mflac / kgma / kwm 等）。

> 合规声明：本软件仅支持普通音频格式转换，不支持任何音乐平台的加密特殊格式。请支持正版音乐，尊重创作者。本软件仅供个人免费使用，禁止商业售卖/转卖/套壳换皮重新发布。作者：牢蜂（LaoFeng）。

## 新增与改进（自 v0.5.2）

- PDF → Word 排版修复（docengine 引擎）：
  - 页眉/页脚自动擦除（跨页重复文本 + 罗马/阿拉伯页码），不再插入正文
  - 编号标题（1.1、一、）独立成段，不再与正文合并
  - 封面/表单「标签：值」分行正确（标签列、值列各自独立）
  - 目录点线行、参考文献条目独立成段
  - 修复离群检测误杀右边缘表格列（装箱标签「二维码」列丢失）——1101 类单据 85.9% → 100%
- PDF → Excel：扫描件结构化识别（docstructure 引擎，PP-StructureV3）支持中文路径
- 字符保留率：10 样本回归全绿（论文/通知/行程册/送货单 99.6-100%）

## 修复

- 自动更新脚本移除（不再自动检查/下载更新）
- 合规声明全面更新（README 中英 / 软件 UI / 诊断文件）

## 已知说明

- 电子发票、箱唛等表格密集文档建议转 XLSX（结构化识别）；DOCX 转换存在 pdf2docx 表格固有局限
- 扫描版 PDF（无文字层）转 DOCX 需 OCR，转 XLSX 走结构化识别
