# v0.6.1 Release Notes

> 合规版（部分格式已下架）。音频仅支持普通格式转换，不支持其他音乐平台的加密特殊格式。
> 仅供个人免费使用，禁止商业售卖/转卖/套壳。请支持正版音乐。

## 更新内容（2026-08-15）

### ICO 图标转换增强
- **PNG/JPG → ICO 尺寸自适应**：不再固定生成 16~256 七档。
  小尺寸源图（如 48px）不再强行放大生成 128/256 模糊帧，只生成不超过源图尺寸的帧
  （保底保留 16/24/32 小图标档）；大图（256px 及以上）仍生成完整七档。
- **ICO → 其他格式多帧提取**：底层新增 `extractAllFrames`，支持提取 ICO 容器内的
  全部尺寸帧（PNG 帧与 BMP DIB 帧均支持），为后续「一键导出全套图标」预留能力。

### 回归保障
- 全量测试 438 项：437 过 + 0 失败 + 1 跳过（ICO 相关新增 2 项）。
- 内置 PDF 引擎（docengine）与 docstructure 引擎、单词书分类修复等均与 v0.6.0 一致。
