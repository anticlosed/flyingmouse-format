## 〇、当前版本定位与渠道边界

**本仓库源码区分桌面版和 Microsoft Store 版：**

- **非 Microsoft Store 桌面版**接受 NCM / KGG / mflac / mgg / kgma / mmp4 / KWM 输入，并转换为普通音频格式 MP3 / WAV / FLAC / M4A / AAC / OGG / OPUS / WMA
- **Microsoft Store 版**通过 `unlockAudioInputs` 隐藏并拒绝上述特殊音频转换入口
- KGG、mflac、KWM 标记为实验性；NCM 的 Audio Vivid（AV3A）音轨仅支持 Windows；部分 QQ Music musicex 输入需要已有授权和在线密钥服务
- 各渠道版本、签名和发布时间必须分别核对；现役状态统一见 [0.7.10 修复与发布记录](REPAIR-0.7.10.md)，不能从 GitHub 最新版推断商店或客户端已升级

## 五、常见问题
- **Q：哪些版本支持特殊音频输入？** A：非 Microsoft Store 桌面版接受 NCM/KGG/mflac/mgg/kgma/mmp4/KWM；Microsoft Store 版不提供特殊音频转换。
- **Q：特殊输入能转成什么？** A：只能转为普通音频目标，不提供视频容器目标；KGG、mflac、KWM 属于实验性输入。
- **Q：QQ Music musicex 为什么可能需要网络？** A：部分文件需要向官方 QQ Music 接口请求密钥；只应处理拥有合法使用权且已有授权的文件。
